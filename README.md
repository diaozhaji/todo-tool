# 待办清单（单文件版）

一个**零依赖、零安装**的待办清单工具，整个程序就是一个 HTML 文件（`待办清单.html`）。

- **文件即数据**：数据直接内嵌在 HTML 文件里，改完自动写回该文件，可以直接像 `txt` 一样复制、移动、发微信。
- **无需服务器 / 数据库**：双击用浏览器打开即用，断网也能跑。
- **功能齐全**：新增、勾选、编辑、删除、截止日期智能识别、日历选择、逾期提醒、排序、导出、统计。

---

## 一、快速开始（3 步）

1. **下载** 本项目里的 `待办清单.html` 到你电脑任意目录（建议放到一个好找、不常移动的文件夹）。
2. **用 Chrome 或 Edge 打开**它（见下方「浏览器要求」，**不要用 Safari / 火狐**）。  
   打开方式：右键文件 → 打开方式 → Google Chrome / Microsoft Edge；或直接把文件拖进浏览器窗口。
3. 第一次打开后，点页面顶部右侧的 **「📎 绑定本文件（自动保存）」**，在弹出的文件选择框里**选中这个 HTML 文件自己**。  
   看到绿色提示 **「✅ 已绑定 xxx.html · 改动自动写入文件」** 就成功了 —— 之后你所有的增删改都会**自动存回这个文件**。

> 绑定只需做一次。下次再用 Chrome 打开同一个文件，如果提示「需要重新授权」，点一下「重新连接文件」即可。

---

## 二、浏览器要求（重要 ⚠️）

本工具要「直接改写本地文件」，依赖浏览器的 **File System Access API**，该 API **只有 Chromium 内核浏览器才支持**。

| 浏览器 | 能否自动保存到文件 | 说明 |
| --- | --- | --- |
| **Google Chrome**（86+） | ✅ 支持 | **推荐** |
| **Microsoft Edge**（86+） | ✅ 支持 | **推荐** |
| Brave / Opera 等其他 Chromium 内核 | ✅ 支持 | 可用 |
| **Safari**（macOS / iOS 默认） | ❌ 不支持 | 会出现「当前浏览器不支持直接写文件」提示 |
| **Firefox** | ❌ 不支持 | 同上 |
| 微信 / QQ 等内置浏览器 | ❌ 不支持 | 请用系统 Chrome/Edge 打开 |

> **macOS 用户特别注意**：双击 `.html` 文件默认是用 **Safari** 打开的，而 Safari 不支持该功能。
> 请**右键 → 打开方式 → Google Chrome**，或把 Chrome 设为默认浏览器。

**如果只能用 Safari / Firefox 怎么办？**  
页面会自动降级，顶部出现 **「⬇ 下载 HTML」** 按钮。每次改完点一下，浏览器会下载一份更新后的 `待办清单.html`，**用它覆盖替换原文件**即可（相当于手动保存，略麻烦但可用）。

## 三、如何保存（重点）

本工具有**三层保存机制**，从好用到兜底依次是：

### 1) 绑定文件 → 全自动保存（推荐）
- 操作：点 **「📎 绑定本文件（自动保存）」** → 选中该 HTML 文件本身。
- 效果：此后任何改动（增/删/改/勾选/排序）都会**自动写回该文件**，无需手动操作。
- 你会看到底部短暂出现「已保存」提示。
- 原理：改动会做 **400ms 防抖**后写入，避免频繁写盘。

### 2) 未绑定文件 → 暂存浏览器缓存
- 没绑定文件时，改动会先存在浏览器 **localStorage** 里（提示「已暂存本机（未绑定文件）」）。
- 注意：**缓存是按「文件位置 + 浏览器」隔离的**，换电脑、换浏览器、或文件被移动后缓存可能读不到。
- 所以**强烈建议绑定文件**，让数据真正落在 HTML 文件里，而不是浏览器缓存中。

### 3) 兜底 → 下载替换
- Safari / Firefox 不支持绑定时，用顶部 **「⬇ 下载 HTML」** 导出最新 HTML，手动替换原文件。

> **数据到底存在哪？**  
> 每次保存都会把数据写进 HTML 里的 `<script id="todoData" type="application/json">…</script>` 这一行。  
> 也就是说，**这个 HTML 文件本身就是你的数据库**，把它复制走 = 把数据带走。

### 换电脑 / 分享给别人
- 直接把 `待办清单.html` 拷给对方即可，打开就是他看到的最新数据。
- 不需要导数据库、不需要账号。

## 四、功能与使用说明

### 添加待办
页面底部输入框，从左到右：
1. **待办内容**（必填，回车即可添加）
2. **负责人**（可选）
3. **截止日期**（可选，支持自然语言，见下）
4. 点 **「添加」**（或按回车）

### 截止日期智能识别
输入框里可以直接写自然语言，会实时提示识别结果：

| 写法 | 含义 |
| --- | --- |
| `10-20` / `10/20` / `10.20` | 今年 10 月 20 日 |
| `2026-10-20` / `2026年10月20日` | 指定日期 |
| `10月20日` | 同上 |
| `今天` / `明天` / `后天` / `大后天` | 相对天 |
| `下周三` / `本周五` | 相对周 |
| `+3d` / `-2d` / `+1w` / `3天后` / `2周前` | 相对偏移 |
| `月底` / `下个月底` | 月末 |
| `1020` / `261020` | 紧凑数字（6/8 位） |

- 也可以点输入框右侧的 **📅**，用弹出的**日历**直接选日期（含「今天 / 明天 / 后天 / 本周五 / 下周三 / 月底」快捷按钮）。
- 无法识别时，会**按文字原样显示**，不会丢失输入。

### 操作待办项
- **勾选完成**：点左侧方框。完成项会显示删除线。
- **编辑**：鼠标移到某行 → 点 **✎**，可改内容、负责人、截止日期、备注（支持 `✓` / `×` 备注高亮）。
- **删除**：点 **✕**，有二次确认弹窗，防误删。

### 顶部统计与信息
- **共 N 项 / 已完成 / 已逾期**：实时统计。
- 顶部一行显示今天日期，以及「未来 3 天内到期 N 项」提醒。
- 每条待办的截止日期会显示徽章：`今天到期`、`明天到期`、`还剩 N 天`、`已逾期 N 天`（颜色区分）。

### 工具栏
| 按钮 | 作用 |
| --- | --- |
| **按截止日期排序** | 按截止日期从早到晚排序（再次点击取消） |
| **重置勾选** | 清空所有勾选状态 |
| **导出数据** | 导出为 `制卡技术待办清单.txt` 文本 |
| **清空重建** | 清空全部数据并恢复默认（**不可撤销**，有二次确认） |

## 五、常见问题（FAQ）

**Q1：为什么提示「当前浏览器不支持直接写文件」？**  
A：你在用 Safari / Firefox / 内置浏览器。改用 **Chrome 或 Edge** 打开即可；或使用「⬇ 下载 HTML」手动替换。

**Q2：改了内容但文件没变？**  
A：确认顶部状态是 **✅ 已绑定 …html**（绿色）。若显示「需要重新授权」，点按钮重新授权一次。

**Q3：换台电脑打开，数据没了？**  
A：说明之前只在浏览器缓存里，没绑定写回文件。请始终确保已绑定。数据真正存在 HTML 文件内，文件拷到哪数据就在哪。

**Q4：绑定后文件被移动了怎么办？**  
A：需要重新绑定一次（指向新位置的文件）。

**Q5：会不会把示例数据一起保存？**  
A：示例数据只是初始默认值，你「清空重建」或直接编辑删除即可，保存时会随之更新。

**Q6：能多人协作 / 云同步吗？**  
A：不能。它是本地单文件工具，协作请把文件放到共享盘/网盘，或各自维护副本。

## 六、原理与数据结构（给好奇的你）

- **读取**：页面启动时优先读文件内嵌的 `todoData` JSON，其次读 localStorage 镜像，**取时间戳较新的**，两者取其一保证不丢改动。
- **写入**：
  - 写 localStorage 镜像；若已绑定文件，再把最新数据重新拼进 HTML 模板，通过 `createWritable()` 写回文件。
  - 文件句柄用 **IndexedDB** 记住，下次打开可续用（可能需要重新授权）。
- **数据格式**：

  ```json
  {
    "updatedAt": 1790576169124,
    "items": [
      { "id": 1, "text": "整理接口文档", "note": "", "owner": "张三", "deadline": "2026-09-30", "deadlineText": "" }
    ],
    "checked": { "2": true },
    "sortByDeadline": false
  }
  ```

  - `deadline` 为识别成功的 `YYYY-MM-DD`；识别失败的原文字存在 `deadlineText`。
